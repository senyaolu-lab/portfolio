# 案例拆解：《女神异闻录 5》—— 日历系统与风格化 UI 的双重设计资产

> 作品类型：案例拆解报告 | 作者：吕森垚 | 版本 v1.0
> 拆解对象：Atlus《女神异闻录 5》（Persona 5，含皇家版），本拆解基于游玩体验与公开资料。

---

## 0. 产品概览

| 项 | 内容 |
|---|---|
| 游戏 | 女神异闻录 5（Persona 5） |
| 开发商 | Atlus |
| 类型 | JRPG / 校园日常 + 异世界冒险 |
| 系列销量 | 系列累计千万级（公开资料） |
| 一句话定位 | 用"日历"把校园日常与迷宫冒险缝合成一款时间管理游戏 |

## 1. 拆解目标

P5 最独特的是"日历系统"与"风格化 UI"。本次拆解回答：**日常与冒险两种完全不同的玩法，如何靠"时间"这个资源合为一体？风格化 UI 又如何从视觉选择升级为品牌资产？**

## 2. 核心循环

白天行动（上课 / 打工 / 培养协力者）→ 放学与夜晚行动 → 进入异世界宫殿限时攻略 → 剧情事件 → 日期推进。每一天都是有限的"行动点"分配题，现实日历同时是倒计时与养成节奏器。

## 3. 关键系统拆解

| 系统 | 设计要点 | 作用 |
|---|---|---|
| 日历与行动点 | 每日上下午各若干行动机会，日期推进触发剧情 | 把"时间"变成核心资源，日常与冒险互相争夺 |
| 宫殿与预告信 | 盗窃目标限时完成，发出预告信后进入倒计时 | 给自由日常一个硬性目标锚点 |
| 协力者（Coop） | 社交链接：日常剧情 + 战斗增益 + 新人格面具解锁 | 社交系统与战斗系统互相强化，而非并行 |
| 弱点与 1 More | 击破弱点追加行动，全倒触发总攻击 | 回合制战斗的节奏放大器 |
| 风格化 UI | 红黑撞色、斜切排版、动态菜单 | 重复操作被视觉包装，UI 本身成为记忆点 |

## 4. 我的洞察

1. **"日常"与"冒险"互为对方的目的**：日常养成让战斗更强，战斗推进解锁更多日常内容——两者不是两个玩法，而是一个循环的两半，玩家对"明天"永远有期待；
2. **协力者系统是 JRPG 社交设计的答案**：把"好感度"从数值变成有剧情、有战斗收益、有收集价值的三重钩子；
3. **UI 是 JRPG 被低估的品牌资产**：当同类游戏的菜单千篇一律时，P5 的风格化 UI 让"打开菜单"这个高频动作本身成为品牌记忆——视觉风格参与留存。

## 5. 问题与增量设计

**我识别的问题**：
1. 宫殿攻略的迷宫结构后期重复感明显；
2. 日历系统的"最优解"一旦被攻略化，自由选择退化为抄作业。

**增量设计**：
- **宫殿动态房间**：每周目随机化宫殿的部分房间结构与宝箱位置，让"最优解"失效，恢复探索感；
- **日程扰动事件**：在日历中随机插入"临时事件"（如突然的考试、同伴求助），打破固定日程表，让时间管理保持紧张。

## 6. 可迁移原则

1. **用"时间"统一两种玩法**：把现实时间做成资源，日常与冒险就不再割裂；
2. **社交系统要为战斗服务**，否则只是双倍的打工；
3. **高频操作值得最高成本的视觉投入**：UI 风格化是最便宜的留存手段之一。

## 7. 结论

P5 证明：JRPG 的差异化不一定要靠新战斗系统，把"日常"做成玩法、把"菜单"做成品牌，同样能成就一代名作。本拆解用于展示我对**系统循环、时间管理与视觉设计参与留存**的理解。
