# 活动策划案：《边陲协议》春节大版本 + 流失召回

> 运营载体：《边陲协议》（虚构）| 文档版本 v1.0 | 作者：吕森垚

---

## 1. 活动背景与目标

| 目标 | 指标 | 目标值 |
|---|---|---|
| 拉新/回流 | 春节期 DAU | 环比 +50% |
| 召回流失玩家 | 召回回归率 | ≥ 10% |
| 付费峰值 | 春节期充值额 | 全年第二峰值（仅次于周年庆） |
| 内容激活 | 春节限时模式参与率 | ≥ 60% |

## 2. 活动组合（大版本 = 四件套）

| 模块 | 内容 | 类型 |
|---|---|---|
| 1.  限时模式 | "瑞雪鏖战"（节日主题战场：烟花特效 + 雪地地图） | 内容 |
| 2.  登录福利 | 春节 7 天签到 + 全服红包雨 | 福利 |
| 3.  限定皮肤 | 春节限定套装（限时上架，节后下架） | 付费 |
| 4.  流失召回 | 老玩家回归礼包 + 好友召回任务 | 召回 |

## 3. 限时模式设计（核心内容）

- **规则**：在大战场模式上叠加节日皮肤（雪地地图 + 烟花粒子 + 节日音效），不改核心玩法，**低成本复用现有模式**；
- **专属掉落**：限时模式内掉落"红包碎片"，集齐兑换限定挂件——用限时奖励驱动参与；
- **时长**：2 周，制造"错过等明年"的稀缺感。

## 4. 流失召回设计（大型网游的必修课）

| 环节 | 设计 |
|---|---|
| 召回对象 | 30 天未登录的流失用户 |
| 召回手段 | 站内信 + 短信/推送（"你常玩的《边陲协议》春节上新了"） |
| 回归礼包 | 回归即领：7 天限定体验皮肤 + 双倍经验卡 + 回归任务线 |
| 好友召回 | 老玩家邀请回归，双方都得奖励（社交裂变） |
| 回归保护 | 回归首周匹配进入"回流保护池"，避免被老玩家血洗挫败 |

## 5. 奖励与防刷

| 场景 | 规则 |
|---|---|
| 红包雨小号多开 | 红包为绑定资源不可交易；红包雨限每日领取次数 |
| 回归礼包反复领取 | 仅"真实流失 30 天"账号触发，且单账号限领 1 次 |
| 跨天/时区 | 服务端按服务器时区结算 |

## 6. 埋点与验证

| 埋点 | 看什么 |
|---|---|
| 限时模式参与率 | ≥ 60% |
| 回归率 / 回归后次留 | 召回质量 |
| 春节皮肤销量 | 付费峰值验证 |
| 回归玩家 7 日留存 | 是否"召回来又流失" |

## 7. 风险与预案

| 风险 | 预案 |
|---|---|
| 春节人力紧张（版本 bug） | 提前 2 周封板测试，春节只做"活动开关" |
| 召回玩家体验差二次流失 | 回归保护池 + 新手向引导 |
| 限时模式挤占排位人流 | 限时模式与排位错峰（白天限时/晚上排位） |
