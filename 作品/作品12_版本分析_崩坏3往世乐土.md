# 版本分析：《崩坏 3》往世乐土 —— 动作手游里的"构筑型 Roguelite"

> 作品类型：版本玩法分析 | 作者：吕森垚 | 版本 v1.0
> 分析对象：《崩坏 3》5.0 版本加入的常驻玩法"往世乐土"，基于游玩体验与公开资料。

---

## 0. 玩法概览

| 项 | 内容 |
|---|---|
| 所属游戏 | 崩坏 3（米哈游） |
| 玩法 | 往世乐土（Elysian Realm） |
| 加入版本 | 5.0（2021 年） |
| 类型 | 动作 Roguelite / 构筑型 |
| 一句话定位 | 用"刻印"把玩家已经养成的角色重新随机化，让重复战斗每一局都不一样 |

## 1. 拆解目标

动作手游的核心矛盾是：角色与操作是固定的，但长线内容需要新鲜感。本次拆解回答：**往世乐土如何用 Roguelite 的"随机构筑"，给一套固定动作系统带来持续的重玩价值？**

## 2. 核心循环

选择角色与难度词条 → 逐层选择房间（战斗 / 事件 / 商店）→ 获取刻印构筑流派 → 挑战 Boss 层 → 结算奖励。每一局都以"这把怎么胡"为驱动力。

## 3. 关键系统拆解

| 系统 | 设计要点 | 作用 |
|---|---|---|
| 刻印系统 | 按英桀流派划分的刻印池，集齐套装触发强力效果 | 构建"流派"（build）的核心，替代局外养成差异 |
| 难度词条 | 玩家自选负面词条换取更高得分与奖励 | 难度自选，一份内容覆盖全部练度 |
| 房间选择 | 战斗 / 事件 / 商店三类房间随机生成 | 路线决策 + 随机性的平衡点 |
| 追忆之键 | 与剧情联动的特殊强化 | 叙事与玩法奖励合一 |
| 剧情叙事 | 十三英桀与爱莉希雅的剧情线 | 用故事给重复刷取提供长期目标 |

## 4. 我的洞察

1. **"随机构筑"是对固定角色的二次随机化**：玩家养成的角色是确定的，刻印体系在局内重新洗牌他的技能组合——同一个角色每周目都有新解，**用配置项代替新内容**，成本远低于做新角色；
2. **难度词条 = 内容利用率最大化**：与《明日方舟》危机合约同理，自选难度让"打得过"和"打不过"的玩家都能在能力上限附近游玩（本作品集的危机合约拆解与此互为印证）；
3. **剧情是重复刷取的防腻剂**：纯粹的周常奖励会腻，把主线级剧情拆进常驻玩法里，玩家的重复行为就有了叙事回报。

## 5. 问题与增量设计

**我识别的问题**：
1. 刻印池随版本膨胀后，局内"三选一"的随机方差变大，成型难度上升；
2. 高难词条下最优解趋同，构筑多样性被压缩。

**增量设计**：
- **刻印保底词条**：每局开局自选 1 个"本局倾向"（如某流派概率提升），把方差控制交给玩家，同时天然引导尝试冷门流派；
- **周常禁用池**：每周随机禁用 2-3 个强势刻印，用"环境轮换"逼出新的构筑解法，类似竞技游戏的 Ban 位思路。

## 6. 可迁移原则

1. **长线玩法优先复用角色资产，用随机构筑替代新内容**；
2. **难度自选是重复玩法最便宜的新鲜感来源**；
3. **把剧情拆进常驻玩法，让重复劳动有叙事回报**。

## 7. 结论

往世乐土证明：动作手游的常驻玩法不需要新角色，一套"刻印 + 词条 + 剧情"的 Roguelite 框架，就能让固定角色池产生接近无限的重玩价值。本分析用于展示我对**常驻玩法设计、Roguelite 构筑与长线内容运营**的理解。
