# 活动策划案：《三角洲行动》× 拍卖行「藏品之夜」联动

> 作品类型：联动活动策划案（提案） | 作者：吕森垚 | 版本 v1.0
> 说明：联动对象以国际知名拍卖行（方案中示意为苏富比）为假设，属设计练习提案，非实际合作计划。游戏机制描述基于公开资料。

---

## 0. 活动概览

| 项 | 内容 |
|---|---|
| 活动名称 | 藏品之夜（The Collection Night） |
| 联动对象 | 国际知名拍卖行（示意：苏富比） |
| 活动类型 | 品牌联动 + 限时玩法 + 社交展示 + 外观商业化 |
| 活动时长 | 4 周（含 2 场全服拍卖夜） |
| 载体模式 | 烽火地带（搜打撤）为主，大战场做配套任务 |
| 一句话定位 | 把"摸金"的核心爽点，升级为一场有鉴定、有竞拍、有展厅的高价值藏品盛宴 |

## 1. 联动逻辑：为什么是拍卖行

判断一次联动是否成立，关键是看品牌能否**强化游戏本身的核心 fantasy**，而不是简单贴 logo。

| 维度 | 三角洲的既有资产 | 拍卖行品牌的加成 |
|---|---|---|
| 核心体验 | 搜刮高价值物资、评估风险与收益 | "高价值物品"的权威象征，天然贴合 |
| 既有系统 | 玩家驱动的交易行与市场价格 | 拍卖形式为交易行提供"高光仪式感" |
| 叙事基调 | 战术、拟真、硬核 | 藏品、鉴定、传承，提升物品的故事性 |
| 用户结构 | 核心玩家 + 泛化用户 | 拍卖行的圈层话题性，有利于破圈传播 |

**结论**：这不是一次"贴皮联动"，而是**用外部品牌的语义，把游戏已有的交易系统做一次体验升级**——成本低、契合高、可复用。

## 2. 活动目标与指标

| 目标 | 指标 | 目标值（示例假设） |
|---|---|---|
| 拉活 | 活动期 DAU 环比 | +15% |
| 提参与 | 鉴定玩法参与率 | ≥ 55% |
| 提社交 | 展厅访问 UV / 每日 | 人均 ≥ 1.5 次 |
| 变现 | 联动限定外观购买率 | ≥ 8% |
| 控风险 | 活动币通胀率 | 控制在 ±10% 内 |

## 3. 核心玩法设计（五个模块）

### 3.1 藏品鉴定（入口玩法）

- 活动期地图新增"藏品点"（如旧金库、私人展柜），掉落**未鉴定藏品**，分普通 / 稀有 / 传世三档；
- 带回局外后需支付**鉴定费**才能揭示价值：普通 500、稀有 5,000、传世 50,000（活动币）；
- 鉴定结果概率公示（合规红线），并设每日首鉴定保底（防挫败）；
- **设计意图**：把"搜到东西"变成"开奖时刻"，为物品附加一层期待感与故事性。

### 3.2 全服拍卖行（社交竞拍）

- 每周开放全服拍卖场，玩家将鉴定后的藏品上架，其他玩家用活动币竞价；
- 成交抽取 **5% 手续费**由系统回收，作为货币回收阀门；
- 顶级藏品**每日限量产出**（稀缺性控制），保证竞拍有真实竞争；
- **设计意图**：让玩家之间的博弈（而非只与系统交易）成为活动的情感高点。

### 3.3 藏品之夜（周末限时高光）

- 每周六晚 20:00 开启全服同步拍卖：倒计时竞价、实时出价播报、成交特效；
- 单场只拍 3-5 件"镇馆级"藏品，制造稀缺与围观；
- **设计意图**：把分散的竞拍聚合成一个"全服共同事件"，为直播与社区二创提供素材。

### 3.4 藏品展厅（社交炫耀）

- 玩家可在个人展厅陈列藏品，好友与全服玩家可参观点赞；
- 展厅按藏品总价值与稀有度生成排名，赛季末结算荣誉标识；
- **设计意图**：给收藏行为一个展示场，把"我有"变成"别人看得见"。

### 3.5 联动外观与叙事

| 内容 | 形式 | 说明 |
|---|---|---|
| 拍卖师白手套 | 手部外观 | 呼应拍卖行的仪式感 |
| 鉴定放大镜 | 挂件 | 可在检视动作中使用 |
| 藏宝箱背包 | 背饰 | 显示藏品数量层级 |
| 拍卖锤 | 近战武器外观 | 联动最具辨识度的符号 |
| 专家 NPC 任务线 | 剧情任务 | 由拍卖行专家讲述藏品背景，把道具变成故事 |

**商业化原则**：全部为外观，**不卖数值、不卖鉴定概率**。

## 4. 奖励与数值设计（示例）

| 来源 | 产出 | 回收 |
|---|---|---|
| 藏品点掉落 | 未鉴定藏品 | 鉴定费消耗活动币 |
| 拍卖成交 | 卖方获得活动币 | 5% 手续费系统回收 |
| 每日任务 | 活动币、图鉴碎片 | 活动结束后活动币清零 |
| 保底机制 | 每日首鉴必得保底价值 | — |

**数值原则**：产出略大于消耗（保证参与感），但通过**手续费 + 活动币清零**两条阀门控制通胀。

## 5. 商业化联动设计

| 商品 | 定价形式 | 定位 |
|---|---|---|
| 联动限定外观（4 件套） | 直购 | 主要收入来源 |
| 藏品之夜通行证 | 赛季通行证联动 | 绑活跃 |
| 展厅扩容 | 可选付费 | 外观向，不影响玩法 |

## 6. 活动排期（4 周）

| 周次 | 主题 | 核心动作 |
|---|---|---|
| W1 | 预热与上线 | 鉴定玩法上线、联动外观上架、专家 NPC 任务开篇 |
| W2 | 首场全服拍卖 | 开放拍卖行、周末首场"藏品之夜" |
| W3 | 高潮 | 藏品之夜 + 图鉴收集冲刺 + 社区二创活动 |
| W4 | 收官 | 最终拍卖夜、展厅排名结算、限定外观下架 |

## 7. 防刷与异常处理

| 场景 | 处理方案 |
|---|---|
| 工作室批量刷藏品 | 藏品账号绑定不可交易；参与竞拍需信誉分门槛；异常交易监控 |
| 小号抬价 | 同一设备多账号出价限制；异常出价风控 |
| 快速连点抢拍 | 出价按钮防重复提交，服务端校验 |
| 活动币通胀 | 手续费回收 + 活动结束清零 |
| 结算未到账 | 先落库后发放，异常走补偿工单 |

## 8. 合规与风控（本方案的关键难点）

竞拍类玩法最大的风险是被质疑为"赌博"，因此必须从机制上排除：

| 风险点 | 规避设计 |
|---|---|
| 变相赌博 | 竞拍**只用活动内产出的货币**，不可充值购买；活动币不可提现、不可兑换真实价值 |
| 概率不透明 | 鉴定概率公示 + 每日保底 |
| 未成年人 | 竞拍功能对未成年账号关闭 |
| 诱导消费 | 联动外观明码标价，不做概率售卖 |
| 舆情"割韭菜" | 活动奖励以荣誉与收藏为主，付费只买外观 |

## 9. 埋点与验证

| 埋点 | 阈值与判断 |
|---|---|
| 鉴定参与率 | ≥ 55%，低于则检查藏品点密度与鉴定费门槛 |
| 拍卖成交率 | 上架成交量 ≥ 60%，低于则调手续费或稀缺度 |
| 展厅访问 UV | 人均 ≥ 1.5 次/日，低于则检查入口曝光 |
| 联动外观购买率 | ≥ 8% |
| 活动期 DAU / 回流 | DAU +15%，回流占比 ≥ 10% |

## 10. 风险与预案

| 风险 | 预案 |
|---|---|
| 竞拍冷场 | 官方托底竞价（NPC 收储）保证最低成交价 |
| 藏品价值超预期膨胀 | 顶级藏品限量 + 手续费回收 |
| 与现有交易行冲突 | 活动藏品独立标记，活动后转为不可交易展示品 |
| 玩家抱怨"变味" | 强调外观与收藏属性，不动竞技平衡 |

## 11. 可迁移方法论

1. **联动要选强化核心 fantasy 的品牌**：摸金 → 拍卖行，是"语义自然衔接"的最佳范例；
2. **优先复用游戏已有系统做联动底盘**：交易行已是现成基建，成本低、契合高；
3. **竞拍玩法必须先解决合规与通胀两个问题**，否则收益再高也不能上；
4. **用"稀缺 + 仪式感"制造高光时刻**：藏品之夜把分散行为聚成全服事件。

## 12. 结论

本方案的核心判断是：联动的价值不在于"贴谁的 logo"，而在于能否用外部品牌的语义，把游戏已有系统的体验升级一次。「藏品之夜」把三角洲的摸金爽点，升级成鉴定、竞拍、展厅与全服拍卖夜的完整体验链，同时用外观商业化与合规设计守住公平与口碑底线。
