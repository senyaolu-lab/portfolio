# 商业化方案：《边陲协议》皮肤与外观

> 运营载体：《边陲协议》（虚构）| 文档版本 v1.0 | 作者：吕森垚

---

## 1. 外观付费的定位（FPS 的收入主力）

大型竞技 FPS 的商业铁律：**付费不能破坏公平**。所以收入几乎全部来自"不影响战力"的外观（皮肤/挂件/击杀特效/载入动画）。《边陲协议》的外观收入目标占比 **70%**。

## 2. 外观分层与定价锚点

| 品质 | 定价(等值) | 获取方式 | 定位 |
|---|---|---|---|
| 普通 | 6-15 元 | 直购/通行证免费线 | 覆盖全民，制造"有皮肤"习惯 |
| 稀有 | 30-60 元 | 直购 | 主力销售带 |
| 史诗 | 88-128 元 | 直购/通行证付费线 | 高品质核心款 |
| 传说 | 168-258 元 | 限时/直购 | 旗舰款，带特效 |
| 限定/联动 | 抽奖获取 | 限时抽奖箱 | 稀缺 + 冲动付费 |

**锚点设计**：先让玩家在通行证里拿到 1-2 个"史诗"皮肤，建立品质认知，再用"传说/限定"制造向上购买的欲望。

## 3. 限时与稀缺（外观付费的发动机）

- **限时上架 + 到期下架**：皮肤轮换商店，制造"不买就没了"的紧迫感；
- **限定不返场**：赛季段位奖励、周年限定永久绝版，保值老玩家；
- **IP 联动**：与热门 IP 联动外观，拉外部用户进场（联动皮肤通常是付费峰值）。

## 4. 抽奖箱设计（合规红线）

| 项 | 设计 |
|---|---|
| 概率公示 | 各品质概率明文公示（如传说 1.5%、史诗 8%、普通 90.5%） |
| 保底 | 抽满 N 次必出传说（如 60 次保底），杜绝"无底洞" |
| 碎片回收 | 重复外观转为碎片，碎片可兑换其他外观 |
| 未成年 | 抽奖箱对未成年关闭，或受防沉迷限制 |

**合规原则**：概率明示、有保底、可兑换——三条缺一不可，这是外观抽奖的合规底线。

## 5. 零数值通胀（外观付费的护城河）

- 所有外观**仅改变视觉，不改任何数值**（射速/伤害/移动速度一律不变）；
- 皮肤可以"酷"、可以"炫"，但绝不"强"——这既保公平，也保长期付费（玩家为爱买单，而非为强买单）；
- 用"击杀特效/检视动画"等表现层炫技，替代数值炫耀。

## 6. 风险与预案

| 风险 | 预案 |
|---|---|
| 抽奖被指"赌博" | 概率公示 + 保底 + 未成年关闭 |
| 皮肤"贵但丑"卖不动 | 上架前玩家测试投票，爆款才上 |
| 绝版皮肤引发新老玩家矛盾 | 仅限"纪念性限定"绝版，商业皮肤保留复刻通道 |

## 7. 埋点与验证

| 埋点 | 目标 |
|---|---|
| 外观付费渗透率 | ≥ 10% |
| 传说皮肤购买率 | 观察旗舰款吸引力 |
| 抽奖箱人均抽数/保底触达率 | 监控合规与体验 |
| 限时皮肤下架后回收率 | 验证"稀缺"策略 |
