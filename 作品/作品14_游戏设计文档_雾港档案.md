# 《雾港档案》游戏设计文档

> 版本 2.0 ｜ 单人 · 推理 · 一局 15 分钟 · 两夜两案 ｜ AI 审讯
> 一句话：**四个人都在撒谎，只有一个人杀了人。你有 30 小时——或者 28 小时。**

---

## 1. 体验目标

| 目标 | 可验收的判据 |
| --- | --- |
| 30 秒懂 | 开场一句话说清"谁死了、有几个人、你有多少小时" |
| 3 分钟上瘾 | 第一次问话就能拿到"口风"（情报反馈），第一次搜证就能拿到实物 |
| 15 分钟通关 | 最优解 12–13h，平均玩家 24–28h，一局正好一节课 |
| 想再来一局 | 凶手和手法随机；换案之后连人也换 |
| 玩完有所得 | 结案报告给出完整真相时间轴与每个人的结局 |

**设计上刻意不做的事**：不做无限对话、不做自由生成剧情、不做好感度养成。
理由：这些都会稀释"你说的每句话都有代价"这件事。

---

## 2. 两案的结构差异

| | 第七证人（剧院） | 显影（照相馆） |
| --- | --- | --- |
| 核心谜面 | 不在场证明是不是真的 | 密室是怎么成立的 |
| 让玩家卡住的地方 | 四个人都在说谎，谁在说"关于案子的谎" | 门从里面插着，所以"谁进去过"变成了证据 |
| 现场痕迹的作用 | 直接指向凶手 | 只能定位"来过"，**不能定罪** |
| 预算 | 30h | 28h（更紧） |
| 新增的推理动作 | —— | 先破解密室，再用密室反推时间线 |

两案共用同一套规则与引擎。第二案的难度不是靠"加线索"，是靠**把物证的解释权拿走**：
剧院案里，"化妆台下的死扣"几乎就能指认阿野；照相馆案里，"地垫上的靴印"只能说明老吴进过门——
而老吴是第一个发现尸体的人，他本来就该进过门。

## 3. 核心循环

```
① 读案情（免费）
   ↓ 形成第一个假设
② 搜证（3–4h）——买信息，不是买答案
   ↓
③ 问话（1h）——验证假设，或者被带偏
   ↓
④ 出示证据（2h）——把"我知道"变成"你承认"
   ↓
⑤ 指控（0h）——一次性下注
```

节奏曲线：

- **0–5 分钟**：现场 + 一轮问话，拿到"凶手的现场痕迹"→ 出现第一个嫌疑人
- **5–12 分钟**：交叉证词互相矛盾 → 需要花钱去验证 → 时间开始紧张
- **12–18 分钟**：防线打到 0 → 招供 → 指控 → 结案陈词（含完整真相回放）

## 4. 信息设计

### 4.1 五类线索

| 类型 | 作用 | 数量/案 | 例子（剧院 / 照相馆） |
| --- | --- | --- | --- |
| **武器** | 决定"手法"这 18 分 | 1（随手法变） | 少了一盏烛台 / 空了一格的裁纸刀架 |
| **时间** | 把死亡窗口收窄到一分钟 | 1 | 停在 23:38 的怀表 / 停在 22:10 的计时器 |
| **现场痕迹** | 指向凶手，但只证明"来过" | 1（随凶手变） | 化妆台下的死扣 / 地垫上的钉底靴印 |
| **破绽** | 戳破某个人的不在场证明 | 4 | 消防梯泥鞋印 / 签到簿上空白的一格 |
| **私事** | 解释"他为什么可疑但不是凶手" | 4 | 缺页账本 / 烧了一半的旧证件照 |

剧院案另有 2 条"存疑"线索（酒水单、密室黑线），照相馆案把密室线索单独做成一条：
**「门框上勾住的黑棉线」**——它不指向任何人，只解释"插销是怎么从门外拉上的"。

### 4.2 地点 × 成本

| 剧院（19h） | | 照相馆（17h） | |
| --- | --- | --- | --- |
| 后台化妆间 | 4h | 暗房 | 4h |
| 二楼包厢 · 消防梯 | 4h | 门厅 · 柜台 | 4h |
| 配电室 · 后台走廊 | 4h | 阁楼 | 3h |
| 账房 | 4h | 后巷 · 后门 | 3h |
| 后巷 · 侧门 | 3h | 街口岗亭 | 3h |

**设计意图**：现场痕迹告诉你*谁*，破绽线索才能证明*他撒谎*，动机只能从私事线索推。
三样东西分散在不同地点，预算买不齐 → 玩家必须赌。

### 4.3 交叉证词环（骨架）

```
剧院：白鹭 ─▶ 周慕之 ─▶ 苏若晚 ─▶ 阿野 ─▶ 白鹭（闭环）
照相馆：阿禾 ─▶ 程守拙 ─▶ 金姨 ─▶ 老吴 ─▶ 阿禾（闭环）
```

四人各自戳破下一个人，**链是闭合的**，所以无论抽到谁当凶手，都存在一条"纯靠问话"的推理路径。
这条环是测试里的硬不变量：任何一个人没被别人戳破过，测试直接红。

## 5. 数值与平衡

### 5.1 成本

| 项 | 值 | 依据 |
| --- | --- | --- |
| 问话 | 1h | 便宜到可以试探，但 20 次就是 20h |
| 搜查 | 3–4h | 等于"放弃 3–4 次问话"，制造真正的取舍 |
| 出示证据 | 2h | 比问话贵，逼玩家先想清楚再出手 |
| 侧写 | 4h | 一次性的"缩圈"保险，贵到不能当常规手段 |

### 5.2 防线（composure）

| 事件 | 变化 | 说明 |
| --- | --- | --- |
| 初始 | 3 | 三次机会 |
| 戳中软肋 | −1 | 只生效一次；同时给"口风"，指出一个值得搜的地点 |
| 出示他的破绽线索 | −2 | 直接塌一半 |
| 出示他的私事线索 | −1 | 他会认这件私事，但**不等于认罪** |
| 出示无关证据 | 敌意 +1 | 只影响语气，**不影响信息获取** |
| 归零 | 招供 | 无辜者说出自己的秘密，凶手说出作案过程 |

> **关键决定：敌意不惩罚可解性。**
> 很多推理游戏会把"惹恼 NPC"做成"他不理你了"，那是死锁源。这里敌意只改变台词温度，玩家永远不会因为嘴笨而玩不下去。

### 5.3 预算演算

```
剧院：全搜 19h + 问完 4 人 4h + 两次关键出示 4h = 27h / 30h
照相馆：全搜 17h + 4h + 4h = 25h / 28h

最优解（现场 + 凶手破绽所在地 + 两次出示 + 问动机）
  4 + 4 + 2 + 2 + 1 = 13h（或 12h）
  → 剧院剩 17h、照相馆剩 16h，都恰好拿满 5 分时间奖励
```

**故意让"全收集"只剩 3 小时**：想拿 S，就必须靠推理跳过某些地点，而不是靠钱多。

### 5.4 评分

| 项 | 分 | 备注 |
| --- | --- | --- |
| 指认凶手 | 55 | 错了整体 ×0.25 且判 F |
| 手法 | 18 | 4 选 1，需要搜到现场 |
| 动机 | 17 | 4 选 1，**选项不带人名**，必须自己想清楚 |
| 戳破不在场证明 | +5 | 即使防线同时归零，也保留"破绽"这一笔 |
| 剩余时间 | +5 | 每剩 3h 加 1 |

阈值：`S ≥ 92 / A ≥ 80 / B ≥ 66 / C ≥ 50 / D / F（指认错误）`。

## 6. 第二案为什么这么设计（密室）

### 6.1 密室必须被拆成三层，否则就是作弊

1. **机制层**：门是怎么从里面插上的？
   → 物证「门框上勾住的黑棉线」+「插销上缠着同样的一截」。暗房挂底片的棉线，可以从门缝外面拉动插销，再一抽就出来。
2. **时间层**：谁有机会拉那根线？
   → 22:10 死亡，22:00 老吴在后巷，22:05 程守拙二次进门，21:00 阿禾上阁楼。
3. **痕迹层**：谁留下了不该留的东西？
   → 现场痕迹。但它只能定位"来过"，因为发现尸体的人本来就进过门。

三层缺一层，密室就变成"作者说了算"。三层齐了，玩家就能自己把门推开。

### 6.2 让"第一个到现场的人"成为嫌疑人

巡警老吴是全案最自然的嫌疑人：**他有权限、他第一个进门、他的靴印就在地垫上。**
而他真正的秘密（二十年前的一张假证件照）与杀人无关——这正是红鲱鱼的用法：
让玩家先怀疑一个"说得出理由"的人，再用物证把他从嫌疑里摘出去。

### 6.3 第二案为什么"更紧"却不"更多"

线索总数与第一案一样是 12 条，地点一样是 5 个，嫌疑人一样是 4 个。
变的只有三件事：

1. 预算 30 → 28（少一小时，等于少一次问话）。
2. 现场痕迹的"证明力"下降（只能定位，不能定罪）。
3. 密室线索占掉了一个线索位，而它不指向任何人。

**结论：难度来自"信息的解释成本"，不是来自"信息的数量"。**

## 7. 剧本创作规范（可直接复用）

每个嫌疑人必须凑齐**七件套**，缺一件就会破坏可解性：

1. **不在场证明（alibi）**——一句可以被证伪的话。
2. **破绽线索（breaker）**——一件能戳破它的物证，放在某个地点。
3. **私事（secret）**——一件与杀人无关、但足够让他撒谎的事（红鲱鱼）。
4. **动机（motive）**——一句"他为什么可能杀"的短句，成为指控选项之一（**id 全局唯一**）。
5. **软肋（weakness）**——一组会刺激到他的词 + 一句失态台词 + 一个"口风"指向。
6. **侧写（profile）**——一段只描述"行为习惯"、不说名字的画像。
7. **入场（entrance）**——他坐下时的那个动作。

外加三条结构约束：

- **每个人都要被别人戳破一次**（否则某人是无敌的，案子可能无解）。
- **凶手必须有一个只属于他的"现场痕迹"**（否则玩家永远只能靠猜）。
- **每个地点至少 2 条线索**（否则会出现"花钱买空气"的负反馈）。

### 案件包 schema（加一案的成本）

```js
{
  id, code, year, title, venue, tagline, difficulty, difficultyLabel,
  deathWindow,                       // 案情卡上公开的死亡窗口
  rules: { budget, costAsk, costPresent, costProfile, composure, ... },
  victim:   { name, age, role, foundAt, foundBy, foundTime, eulogy, summary },
  suspects: [ ...七件套... ],
  locations:[ { id, name, tag, cost, preview, empty } ],
  cluesByLocation: { 地点: ['weapon','time','trace', ...] },
  staticClues: [ { id, loc, name, detail } ],
  methods:  [ { id, name, weapon, phrase, forensic, clue:{ id:'weapon', name, detail } } ],
  timeline: [ 公开时间线 ],
  profiles, entrances,
  truthTimeline: (culprit) => [ 结案揭晓的完整时间轴 ]
}
```

**加一个案子 = 一个文件 + `cases.js` 里一行。** 引擎、界面、AI、存档都不用动。

## 8. AI 边界（这个设计里最重要的一节）

| 交给模型 | 绝不交给模型 |
| --- | --- |
| 语气的温度、句式、情绪 | 谁有罪 |
| 把三句事实合成一段自然对白 | 新增任何案件事实 |
| 结案陈词的文风 | 时间、地点、数字、证据 |
| 未命中关键词时的意图兜底 | 玩家的得分 |

**做法**：模型拿到的不是"设定"，而是**"你此刻必须说出口的内容"**——一段已经由引擎裁决过的事实。
它做的是"演绎"，不是"编造"。因此：

- 换模型 → 难度不变、真相不变；
- 模型抽风 → 回退本地台词，游戏照常；
- 没网 / 没 key → 本地台词，依然是一局完整的游戏。

角色卡里的年份、场所、死者、现场，**全部来自案件包**，不是写死的文案。

## 9. 新手引导（三层，各管一件事）

| 层 | 出现时机 | 解决的问题 | 形态 |
| --- | --- | --- | --- |
| **教程** | 第一次打开，选案之前 | "这是个什么游戏？我要干什么？" | 4 步弹窗，可跳过 |
| **局内指引条** | 进入对局后常驻顶部 | "我现在该点哪？" | 5 步清单，做一步勾一步，自动推进 |
| **关于本作** | 随时（顶栏 / 选案页） | "为什么这么设计？" | 一段设计说明 + 重看教程 |

### 9.1 教程的四步

1. **你是谁、有多少时间**——警探，30 小时，4 个撒谎的人。
2. **你能做的四件事**——一张成本表：问话 1h / 搜查 3–4h / 出示 2h / 侧写 4h。
3. **一局怎么走完**——现场 → 痕迹 → 破绽 → 出示 → 动机 → 指控（一条流程图）。
4. **可以开始了**——第一分钟做什么，以及"别做的事"。

每步右下角一个"下一步"，左下角留"跳过"。**教程不是关卡**，跳过之后所有信息还能从「关于本作」里找回来。

### 9.2 局内指引为什么做成"清单"而不是"教程关"

- 教程关要写专门的内容、专门的关卡，成本高且只能玩一次；
- 清单是**贴着真实对局走**的：玩家搜完一个地点，第 1 步自动打勾，第 2 步顶上来；
- 五步正好覆盖核心循环（搜查 → 问话 → 戳软肋 → 出示 → 指控），做完就等于走完一局；
- 全部做完就消失，不打扰老玩家；右上角 × 可以随时关掉，并在本地记住。

### 9.3 一条设计原则：引导只指路，不代打

指引告诉玩家"该点哪"，但**绝不告诉玩家"该怀疑谁"**。
任何能直接缩小凶手范围的提示（口风、侧写）都必须花时间买——引导本身不消耗预算，也不泄露答案。

## 10. 失败模式与防呆

| 失败模式 | 处理 |
| --- | --- |
| 时间见底 | 顶栏变红闪烁；只允许指控；底部提示"选错人，案子就烂在你手里" |
| 重复出示同一证据 | 判定 `repeat`，不扣防线，卡片打上"已问过"（防刷分） |
| 搜了空地点 | 返回作者写的"空描述"，不假装有收获 |
| 问了模型没听懂的话 | 关键词没命中时，在线模式多问一次"这属于哪个话题"；离线模式落到"闲谈" |
| 指认错误 | 仍然给出完整真相回放——**要让玩家知道自己错在哪**，这是二周目的动力 |
| 不知道下一步做什么 | 局内指引条永远显示"第一个没完成的动作"；全部完成即自动消失 |

## 11. 可解性证明（工程化）

```
不变量 1：每局恰有 1 个凶手（两案 × 120 seeds）
不变量 2：每条线索恰属 1 个地点；无孤儿线索
不变量 3：每个嫌疑人都有破绽线索 + 私事线索 + 侧写 + 入场
不变量 4：四个人都能被他人证词戳破（环闭合）
不变量 5：现场必有凶手的"现场痕迹"
不变量 6：最优解 ≤ 13h < 预算
不变量 7：动机 id 全局唯一（否则选错人也能拿动机分）
不变量 8：公开的死亡窗口与真相时间轴不矛盾
```

对应 `test/engine.test.mjs` 的 36 个用例；其中"240 局完美通关全部 100 分"是硬门槛。

## 12. 已知的不足

- **画面是纯 CSS**：气质够，但没有角色立绘，情绪全靠文字与排版。
- **技巧天花板有限**：熟练玩家几局之后能背下两案的人设，随机只换凶手不换人。
- **动机选项少**：4 选 1，信息量偏低。
- **没有语音**：语音是审讯品类最自然的交互（参考 MurderMysteryAI），但会引入录音与 STT 依赖，与"零依赖"冲突，故砍掉。

## 13. 第三案设想：法庭对质

把"审讯"推到"当庭对质"：

1. 六个证人，两两互相矛盾，你要在有限提问次数里找出**哪一对不能同时为真**。
2. 引入"陪审团"机制：每一次错误指控降低陪审团信任，信任归零则案子被撤。
3. AI 的新位置：**对方律师**。它不生成事实，只负责"抓住你证词里的漏洞反复追问"——事实仍由引擎给出，模型负责攻击性。
4. 复用现有引擎：线索 / 防线 / 时间三件套不变，只把"出示证据"换成"当庭举证"。
